# @mizook/design

The one Panda preset for the chat, the dashboard, and the pages the agent publishes.

`@mizook/design/preset` holds the tokens: warm paper and dark ink, a magenta accent, square corners, Google Sans for text, IBM Plex Mono for metadata. `@mizook/design/styles.css` loads the fonts and declares the CSS layer order. `@mizook/design/logo` holds the logo as data: the thread mark and the loop that stands for the OO of the wordmark.
